# INCIheinz – Symbolliste (Entwurf)

Format für jedes Symbol: eine SVG-Datei, viewBox 24×24, nur Linie (stroke), keine Füllung, Strichstärke 1,7, abgerundete Enden, Farbe `currentColor`. Dateiname = Schlüssel aus der Liste (z. B. `alarm.svg`). Die Symbole im Prototyp sind Platzhalter von mir.

## Status / Warnung
| Schlüssel | Bedeutung | Hinweis |
|---|---|---|
| alarm | läuft bald ab (MHD) | Wecker |
| pie | knapp, unter Mindestbestand | Pizza/Kuchen mit fehlendem Stück |
| leer | leer / aufgebraucht | gestrichelter Kreis |
| auf-liste | steht schon auf der Einkaufsliste | Einkaufswagen klein |
| geprueft | INCI geprüft | Haken im Kreis |
| ungeprueft | INCI nicht geprüft | Fragezeichen im Kreis |
